# AWSM-DEV Public Feedback & Issue Tracker

Welcome to the official public issue tracker for **AWSM-DEV**. 

Our core source code is private, but we believe in building in public when it comes to listening to our users. We use this repository to track bugs, gather feature requests, and communicate with our community.

## 🚀 How to Contribute

We welcome your feedback! Please use the following links to get started:

- 🐛 [Report a Bug](https://github.com/awsm-dev/awsm-dev/issues/new?template=bug_report.md)
- ✨ [Request a Feature](https://github.com/awsm-dev/awsm-dev/issues/new?template=feature_request.md)

### Guidelines
1. **Search First**: Before opening a new issue, please [search existing issues](https://github.com/awsm-dev/awsm-dev/issues) to see if someone else has already reported it.
2. **Be Descriptive**: Provide as much context as possible. Screenshots and steps to reproduce are incredibly helpful.
3. **Be Respectful**: Please be kind and respectful to maintainers and other community members.

## 🔒 Security Vulnerabilities

If you have discovered a security vulnerability in AWSM-DEV, **please DO NOT open a public issue.** 

Instead, review our [Security Policy](SECURITY.md) for instructions on how to securely disclose the issue to our team.
