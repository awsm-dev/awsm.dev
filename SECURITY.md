# Security Policy

## Supported Versions
Security updates are applied to the live production environment. We kindly ask that you test against the latest live version of the platform.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have found a security vulnerability in our platform, please report it directly to our security team via email:

📧 **[security@awsm.dev](mailto:security@awsm.dev)** *(Update with your actual security email)*

### What to include:
- A description of the vulnerability.
- Step-by-step instructions to reproduce the issue.
- Potential impact.

We take security seriously and will make every effort to respond to your report within 48 hours and provide timelines for a fix.
